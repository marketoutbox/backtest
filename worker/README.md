Deploy this directory as a persistent Python Docker service, with one worker process initially. Configure the variables in ../.env.worker.example, an S3-compatible bucket, and Postgres. Set WORKER_URL and the same WORKER_SECRET in Vercel. Keep the worker URL reachable from Vercel; its routes require X-Worker-Secret. For serious backfills, run a durable job runner/process instead of relying on FastAPI background tasks; this first version stores jobs and restarts queued/running work on process restart. Scale by one process first because the in-process rate limiter is not distributed.
